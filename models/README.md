# Modelo de mãos

Execute `python scripts/prepare_model.py` antes do workshop. O aplicativo lê
`hand_landmarker.task` desta pasta e não faz downloads durante a execução.

Origem: [modelo oficial MediaPipe, float16, versão 1](https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task).

Documentação e termos do fornecedor: [MediaPipe Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Python).
