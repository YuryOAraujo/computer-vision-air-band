# Air Band Lab — checkpoint da primeira noite

Execute `preparar_windows.bat` antes da aula. Requer Python 3.12 de 64 bits.

```powershell
.\.venv\Scripts\python.exe app.py --version day1
```

Para usar mouse: acrescente `--input mouse`.

Edite **versions/day1/project.py**. O painel de quatro sons está completo.
Na segunda noite, altere dados e regras para criar seu instrumento.
As funções e os dados das atividades usam os nomes descritos no
[glossário](docs/GLOSSARY.md).

Leia [o caderno, a partir da segunda noite](docs/STUDENT_GUIDE.md#segunda-noite--escolha-seu-instrumento).
Para instalação, consulte [a preparação](docs/LAB_SETUP.md).
