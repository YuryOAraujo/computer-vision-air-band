# Air Band Lab — projeto inicial

Execute `preparar_windows.bat` antes da aula. Requer Python 3.12 de 64 bits.

```powershell
.\.venv\Scripts\python.exe app.py --version starter
```

Para usar mouse: acrescente `--input mouse`.

Edite **versions/starter/project.py**. O reconhecimento e a janela já funcionam;
o acionamento por gesto depende das duas funções que você vai completar.
A tecla `1` já testa o áudio. Complete `encontrar_area` e `escolher_som`.

Siga [as missões do caderno](docs/STUDENT_GUIDE.md).
Para instalação e problemas de câmera, consulte [a preparação](docs/LAB_SETUP.md).
O [glossário](docs/GLOSSARY.md) explica o vocabulário de programação.
